# Privacy Policy

**Effective date:** 2026-07-20

print-util is a local Windows utility for sending PDF print jobs to printers installed on the user's computer.

## Data collected

print-util does not collect, store, sell, or transmit personal data. It does not include analytics, advertising, telemetry, or background network calls.

## Network access

The application starts a local HTTP server bound to `127.0.0.1`. It accepts requests from software running on the same computer, such as an approved browser extension. It does not listen on network interfaces accessible from other computers.

PDF files and print settings submitted to the local API are processed on the user's computer and sent to the Windows print spooler. They are not uploaded to the developer or any third party by print-util.

## Third-party components

The installer may include third-party PDF and printing components. Their licenses and notices are distributed with the application and remain subject to their respective terms.
